# SR:AIVER 收尾(LINE AI 助理上線前要補的事)

狀態:Draft(2026-11-08 建立)。決定寫進 `docs/decisions.md`。

## 目標
把 LINE AI 助理從「能跑」變成「能給真店家用」:換成真資料、補法律頁面、收乾淨管理後台的授權按鈕。

## 任務
- [ ] 1. 知識庫換成真資料(營業時間、商品、常見問答)。需要老魚提供內容;代理先備好填寫格式與匯入方式。
- [ ] 2. 法律頁面換成正式版(隱私權政策、服務條款)。需要老魚提供或確認文字;代理先備好版面與連結位置。
- [ ] 3. 管理後台「連接 Cloudflare」授權按鈕,在 `admin.aiver.me` 重跑一次授權並驗證可用。
- [ ] 4. 移除用不到的語系,只留繁體中文(缺鍵時退回繁中)。
- [ ] 5. 重設密碼信走完整流程:收信(AgentEmail)→點連結→進重設頁→改密碼→可登入。上次只驗到連結網址正確。
- [ ] 6. 手機整套真人驗收(老魚本人):登入、設定 LINE、知識庫、對話紀錄、用量。

## 驗收
- 每項有證據:測試輸出、截圖路徑或 curl 回傳。分「測到的」與「還沒驗的」。
- 第 6 項由老魚在整合後版本一次驗完;意見記進 `acceptance-backlog.md`,不在本 SR 內邊驗邊修。

## 人類關卡
- 1、2 需要老魚給內容;6 需要老魚本人。其餘代理自行完成。
