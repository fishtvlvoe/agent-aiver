怎麼拿到金鑰？

  1. 到 LINE Official Account Manager 建立官方帳號，開啟 Messaging API
  2. 進 LINE Developers Console → 你的 Channel → Basic settings 複製 Channel secret
  3. 切到 Messaging API 分頁，按 Issue 產生 Channel access token
  4. 關閉「自動回覆訊息」、開啟「Webhook」、關閉「Webhook redelivery」
  5. 把上方 Webhook 網址貼到 Webhook URL，按 Verify
  6. 回到這個頁面按「驗證並儲存」，燈號變綠就完成了
